About & Setup

DAVID ALYI STUDIO — Starter Edition

This is a front-end prototype designed to run in a mobile browser. It provides navigation, local project notes and media previews.

What is not connected yet?

• Real conversational AI

• AI image and video generation

• Cloud database and user accounts

• Professional timeline editing and media rendering

• App packaging and deployment

Security

Never paste an AI API key into this HTML file. The production version must call a secure backend that stores provider keys on the server.

Next development stage

Build and deploy a secure backend, then connect MY AI to a real model. After that, implement the development tools and creative integrations in stages.
