HOW TO OPEN ON ANDROID
1. Extract this ZIP using your phone's Files app.
2. Open the extracted folder in Acode.
3. Open index.html and use Acode Preview, or open the file in Firefox.
4. Saved project notes are stored locally in that browser on that device.

IMPORTANT
This is a front-end starter prototype, not a finished AI service.
The MY AI chat is a demo and does not call an AI model yet.
Image/video generation, advanced editing, cloud accounts, backend APIs and deployment
must be implemented and tested in later stages.

SECURITY
Never put API keys in index.html or any browser-side JavaScript.
A production version needs a server-side backend to keep provider keys secret.
Revoke any API key that was previously exposed in an uploaded HTML file.
